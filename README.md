# ¡Bienvenido a Sins of the Spire!

# ¡Gracias por visitar el repositorio oficial de **Sins of the Spire**!

# Este proyecto es una propuesta de videojuego desarrollada con Unity, en la que buscamos dar vida a una experiencia interactiva a través del diseño visual, la creatividad, la programación y el desarrollo de mecánicas de juego.

# En este repositorio podrás encontrar los archivos del proyecto, recursos gráficos, scripts, escenarios, modelos y diferentes elementos que forman parte de su desarrollo.

# Sobre el proyecto

# Sins of the Spire es un proyecto en constante desarrollo. Nuestro objetivo es construir una experiencia de videojuego que refleje el esfuerzo, la imaginación y el trabajo detrás de cada uno de sus elementos.

# Tecnologías utilizadas

# - Unity – Motor de desarrollo del videojuego.
# - C# – Programación y lógica del juego.
# - Git y GitHub – Control de versiones y colaboración.

# Contenido del repositorio

# - Assets – Recursos, modelos, texturas, escenas y scripts.
# - Packages – Paquetes y dependencias de Unity.
# - ProjectSettings – Configuración del proyecto.

# ¡Gracias por acompañarnos!

# Este repositorio representa el proceso creativo y técnico detrás de **Sins of the Spire**. Cada avance forma parte de la construcción de este proyecto.
